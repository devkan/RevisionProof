- **00:18 시연 시작:** 소개를 마친 뒤 한 호흡 쉬고 “그럼 실제로 편집해 보겠습니다”로 전환한다.

- **02:46 전후 복구:** “이번에는 세 검사 모두 통과했습니다” 앞에서 짧게 호흡하고, 실패와 달라진 결과를 분명하게 전달한다.
- **03:08 마무리:** 마지막 두 문장은 각각 완결해 읽어도 좋다. “최종 결정은 여러분이 합니다”에 힘을 준다.

## 새 음성을 받을 때의 편집 원칙

1. 먼저 문단 전체를 듣고, 문장 사이 억양·호흡을 포함한 자연스러운 발화를 보존한다. 문장·쉼표마다 잘라 화면에 붙이는 기존 45조각 방식을 반복하지 않는다.
2. 자막 생성 → 브랜드 교정 → 무음 탐색, 속도·음량 → 컷 선택 등 이어지는 행동은 연속된 설명으로 배치한다. 특히 “속도를 … 배로”, “초안을 만들고”, “검토한 뒤” 같은 미완결 표현 뒤에 긴 무음을 넣지 않는다.
3. 화면의 버튼 클릭마다 음성 한 조각을 맞출 필요는 없다. 설명이 해당 기능 화면과 겹치도록 하고, 1–2초 정도 앞서 안내하는 흐름도 활용한다.
4. 시간 조정이 필요하면 우선 문단 전체를 앞뒤로 이동하고, 완결된 호흡이나 기능 전환의 쉼에서 조정한다. 단락 안의 발화를 억지로 벌리거나 길이를 맞추기 위해 마지막 음절을 자르지 않는다.
5. 주요 확인 지점은 오프닝 검색 약 00:22, Gemini 초안 약 00:33, 영어 자막 약 01:13, 속도·음량 약 01:27·01:31, 무음 선택 약 01:41, 실패 카드 약 02:29, 재생성 약 02:41, 통과 약 02:46, 최종 승인 대기 약 03:08이다. 이 시각들은 내용 확인용이지 추가 절단점이 아니다.
6. 새 음성의 실제 길이가 화면 범위를 벗어나면, 사용자가 선호한 자연스러운 말 흐름을 우선해 문단별 배치를 검토한다. 낭독 전의 이 시간표만으로 정확한 싱크를 보장하지 않는다.

## 기능 설명의 정확성

- “고쳤고요”는 녹화에서 직접 브랜드 표기를 교정한 행동을 설명한다. “무음 구간을 다시 요청한다”는 새 동작을 덧붙이지 않고, 화면대로 무음 구간을 찾아 검토하는 흐름으로 설명한다.
- 시연에서 만드는 것은 영어 자막이다. AI가 만든 내용은 검토할 초안이며, 사람이 필요한 컷과 최종 승인을 결정한다.
- 검사 통과는 정해진 기준에 따른 결과다. 모든 의미·프레임의 완벽한 일치를 보증한다고 설명하지 않는다.
- 총 11초는 샘플 기반 검토 구간의 합계다. 하나의 연속 구간이라는 뜻이 아니다.
- 잘못된 외부 파일을 자동 수리한 것이 아니라, 선택한 B를 새로 생성해 그 결과를 검사했다.
- 최종 화면은 승인 대기 상태다. 승인·다운로드 완료를 주장하지 않는다.
