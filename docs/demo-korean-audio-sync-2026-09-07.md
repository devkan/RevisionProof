## 음성 배치

입력 MP3의 디코딩 길이는 **143.868979초**다. 기존 한국어 대본의 36개 구간을 실제 발화와 화면에 맞춰 **45개 음성 단위**로 분리했다. 모든 원본 PCM 샘플을 한 번씩 순서대로 사용하고, 전체 194초에 맞춰 **50.131021초의 무음**을 추가했다. 이 수치는 새로 추가한 무음으로, 원본 음성에 이미 있던 쉼은 별도로 보존되어 있다.

## 검증

- v4와 한국어판의 **H.264 비디오 비트스트림 SHA-256 일치**: 모든 5,820프레임과 화면 타이밍 유지.
- 최종 MP4에 비디오 1개와 `kor` 언어의 오디오 1개만 존재. 영어 오디오는 매핑하지 않았다.
- 전체 영상·음성 디코딩 오류 없음. 194초·1080p30·48 kHz 스테레오 확인.
- 원본 음성의 모든 디코딩 PCM 샘플을 빠짐없이 한 번씩 순서대로 사용. 음성 겹침 없음. 속도 1.0배·게인 변경 0 dB.
- WAV의 PCM 변환 오차는 24비트 양자화 범위 이내. 최종 AAC의 45개 구간과 정렬 음성 간 최소 파형 상관계수 약 **0.999948**.
- 추가 무음 중 경계 여유를 제외한 40개 구간이 실제 무음임을 확인. 최종 피크 약 **−2.04 dBFS**, 클리핑 없음.
- 소개·시연 연결, 엔딩 비교, 속도·음량, 잘못된 편집, 차단·재생성·통과, 저장 이력, 최종 승인 화면을 추출해 설명과 대조했다. 무음 선택 장면은 100–104초 화면을 추가 확인한 뒤 설명을 99.400–101.656초로 옮겨 체크 동작에 맞췄다.
- 입력 MP3와 기준 v4의 SHA-256이 작업 전후 동일함을 확인했다.
