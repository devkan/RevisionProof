## 편집 방법

- 새 MP3는 디코딩 기준 **150.900979초**, 48 kHz 스테레오 PCM **7,243,247 샘플 프레임**이다.
- 로컬 faster-whisper로 새 음성을 전사해 대본 순서와 문단 경계를 대조했다. ASR은 고유명사·숫자에서 오인식이 있으므로 녹음용 원문과 인식 결과를 별도로 저장했다.
- 문단 경계 13곳 모두 약 0.74–0.83초 길이의 실제 원본 무음 안에서 분할했다. 각 분할점 앞뒤 100ms, 합계 200ms가 −40 dBFS 미만임을 확인했다.

- **속도 1.0배, 게인 변경 0 dB.** 노이즈 제거, 게이트, 페이드, 시간 늘이기·줄이기 등 말소리를 변형하는 필터를 적용하지 않았다.
- 화면에서 해당 기능을 설명하는 시점에 맞춰 문단 전체를 이동했다. 새로 추가한 무음은 합계 **43.099021초**이며 문단 사이와 영상 양끝에만 있다. 이 무음과 원본에 이미 있던 쉼은 구분한다.
- 자막 생성 → 브랜드 교정 → 무음 탐색, 속도·음량 → 컷 선택, 재생성 → 통과 → 엔딩 비교는 각 문단 안에서 연속 발화를 유지한다. 버튼 동작마다 음성을 잘라 맞추지 않았다.

## 뭉개짐·소리 누락에 대한 검사

파일 전체의 평균 파형만 비교하지 않고 짧은 발화 구간까지 대조했다.

- **원본 보존:** 14개 문단의 모든 원본 PCM 샘플이 정렬 버퍼와 정확히 일치. 내부 음절·호흡·말소리의 잘림, 삽입 무음, 중복 없음.
- **WAV:** 24비트 PCM 양자화 외의 변경 없음. 최대 오차 약 `1.19e-7`.
- **짧은 발화 검사:** 원본 RMS가 −40 dBFS보다 큰 **20ms 구간 10,976개**를 10ms 간격으로 검사했다. 원본과 최종 AAC의 음량 차이는 **−0.096~+0.063 dB**로, 갑작스러운 감쇄나 추가 음소거가 없었다.
- **파형 손상 검사:** 모든 검사 구간에서 원본 대비 신호/오차 비율이 약 **29.97 dB 이상**. 문단별 원본·AAC 파형 상관계수는 최소 **0.99999469**다.
- **재생 타임스탬프:** AAC 패킷 **9,095개**의 시각이 연속적이며, 패킷 사이 누락 구간 없음. 일반 AAC 인코더 프리롤과 끝 패딩은 정상 범위다.
- **스테레오·모노 호환:** 입력과 출력 모두 좌우 채널의 상관계수가 사실상 1이며, 모노 합성 시 위상 상쇄로 소리가 사라지는 문제가 없다.
- **피크:** 최종 약 **−2.13 dBFS**, 클리핑 없음. 원본 입력의 측정 통합 음량은 약 **−15.16 LUFS**다.
- 추가한 문단 사이 무음 구간은 AAC 경계 여유를 제외하고 실제 무음임을 확인했다. 말하고 있는 중간에 넣은 무음과 혼동하지 않는다.

## 영상과 파일 검사

- 원본 v4와 완성본의 H.264 비트스트림 SHA-256 일치. 비디오 재인코딩과 프레임 타이밍 변경 없음.
- 오디오 1개와 비디오 1개만 포함. 영어 오디오는 매핑하지 않았고 한국어 오디오만 사용했다.
- 전체 194초의 비디오·오디오 디코딩 오류 없음. 1080p30, 5,820프레임과 48 kHz 스테레오 확인.
- MP4 faststart 적용. 입력 MP3, v4, 녹음용 대본의 작업 전후 SHA-256 일치.
