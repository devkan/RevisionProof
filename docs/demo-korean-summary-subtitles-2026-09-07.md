## 문구와 표시 기준

- `리비전프루프` → `RevisionProof`, `일점이오배` → `1.25배` 등으로 표기를 정리했다. `Google AI`, `Gemini`, `ClickHouse MCP`, `+6 dB`, `27초`, `11개`, `11초`, 버전 A/B는 녹음용 대본과 시연 기록·화면의 의미를 기준으로 표기했다.
- 예: 긴 자막 생성·브랜드 교정 설명은 **“AI 자막은 검토용 초안 / 브랜드 표기는 직접 수정”**으로 요약했다.
- 예: 실패·재생성·통과 기록은 **“외부 영상 FAIL → 새 버전 B PASS / 저장된 결과로 확인”**으로 요약했다. 잘못된 외부 파일 자체가 고쳐졌다는 뜻이 되지 않도록 새 B 결과를 구분했다.
- 최종 승인 대기와 사용자의 최종 결정은 유지했다. ClickHouse의 11초는 검토가 필요한 구간을 가리키며, 전체 프레임을 빠짐없이 검증했다는 표현은 쓰지 않았다.
- 최대 두 줄, 흰색 **맑은 고딕 Bold**, ASS 크기 52, 검은색 테두리 2.3px, 둥근 검정 배경을 적용했다.
- 배경 투명도는 ASS `0x59` = **34.90% 투명 / 65.10% 불투명**이다. 이전 영어 자막의 스타일과 같다.
- 기본 위치는 하단 중앙이다. A/B 비교·선택 관련 세 자막은 상단으로 옮겨 미리보기 선택 버튼과 오프닝 문구를 보존했다.

## 확인 결과

- 최종 인코딩 파일에서 **37개 자막 모두** 흰 글자 내부 픽셀이 표시되는 것을 확인했다. 잘림·누락 검사 통과, 최대 두 줄 및 자막 간 겹침 없음.
- 고유명사·속도·음량·A/B·ClickHouse·마지막 장면을 포함한 미리보기와 최종 프레임을 확인했다. `MalgunGothicBold` 실제 선택, 누락 글리프 경고 없음.
- 회색 테스트 화면에서 검정 배경 아래 밝기의 약 **34.38%**가 남는 것을 확인했다. 영상 색 변환 오차를 고려하면 요청한 약 35% 투명도와 일치한다.
- 한국어 오디오는 **재인코딩하지 않고 AAC 스트림 복사**했다. 기준 v2와 최종 v3의 **9,095개 오디오 패킷 내용·재생 시각·길이·플래그가 모두 동일**하다. 자막 작업으로 추가된 음성 절단, 음소거, 감쇄, 지연이 없다.
- 비디오·오디오 전체 194초 디코딩 오류 없음. 한국어 AAC 오디오 한 트랙, 48 kHz 스테레오 확인.
- 기준 영상 SHA-256 `e03f8f23cbe0bc43c882a70096b5030693dcfd580fb2207bedeb66ad8904bc20` 유지. 영상은 자막 합성을 위해 H.264 CRF 18로 재인코딩했고, 길이·프레임 수·화면 진행 시각은 유지했다.
