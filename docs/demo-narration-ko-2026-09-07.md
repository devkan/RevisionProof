## 화면과 설명의 일치 기준

- 영어 문장을 그대로 옮기기보다 화면을 보며 이해하기 쉬운 한국어로 줄였다. 소개 → 검색·브랜딩 → 자막·속도·음량 → 잘못된 계획과 결과 차단 → 재생성·검증 → 사람의 승인 순서를 유지한다.
- 01:12.5 구간은 녹화 화면에서 **영어 자막**을 만드는 시연이다. 한국어 내레이션이라고 해서 한국어 자막 생성 시연으로 바꿔 설명하지 않는다. 앱 UI와 원본 영상에 이미 들어 있는 영어 문구도 현재 작업에서는 그대로다.
- 01:01.5의 대기 시간 설명은 이번 데모에서 렌더링 대기를 짧게 편집했다는 뜻이다. 제품의 실시간 처리 속도를 주장하지 않는다.
- “승인한 오디오”는 편집 계획에서 선택한 오디오 기준이다. 완성 영상에 대한 최종 승인이 끝났다는 뜻이 아니다.
- 검사 결과는 고정 기준과 측정값에 따른다. Change Map은 샘플 기반 진단이며 모든 프레임·의미의 완벽한 일치를 보증하는 것으로 설명하지 않는다. 총 11초는 표시된 검토 구간의 합계로, 하나의 연속 구간이라고 단정하지 않는다.
- 02:40.4는 선택한 버전 B를 새로 생성해 검사하는 장면이다. 잘못 올린 외부 파일 자체를 자동 수리했다고 설명하지 않는다.
- ClickHouse 부분은 녹화된 쿼리 이력과 저장된 실패·통과 결과다. 대본 작성 중 새로운 쿼리를 실행하거나 실시간 상태를 재검증한 것은 아니다.
- 마지막 화면은 여전히 사람의 최종 승인 대기다. 최종 승인·다운로드·제출 완료를 주장하지 않는다.

## 다음 음성 교체 작업

1. 사용자가 제공한 한국어 음성을 듣고 전사해 이 대본과 대조한다. 실제 발음·길이·문장 사이 쉼을 확인한다.
2. 기존 영어 내레이션 구간에 억지로 맞추지 않고, 위 화면 구간 안에서 한국어 문장을 배치한다. 필요하면 설명을 화면보다 1–2초 먼저 시작하거나 무음을 둔다.
3. 기준은 영어 내레이션 자막이 번인되지 않은 **v4**다. 영어 자막이 번인된 v5는 한국어판의 기반으로 사용하지 않는다.
4. 기존 영어 오디오 트랙을 교체하고 한국어 오디오만 넣은 별도 MP4와 정렬 WAV·실제 배치표를 만든다. 원본과 영어판은 보존한다.
5. 한국어 자막을 만들 때는 실제 음성의 배치 시각을 사용한다. 이 예정 시간표를 확정 SRT로 취급하지 않는다.
